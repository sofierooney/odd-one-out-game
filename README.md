# Odd One Out

A pass-the-phone impostor party game for 3–20 players. Everyone gets the same secret word except 1–3 randomly chosen impostors, who see the category but not the word. The player list starts with sof, mont, meegs, marj, ava, saff, viv, summz, and lior.

## Play

Open `index.html` in a browser and tap “Enter the circle.” Edit the player list if needed, choose a category (or leave it on Surprise me) and 1–3 impostors, then deal the cards. You need at least 3 players and at least one more player than the number of impostors. The next screen shows a card for every player. Players can tap their own named card in any order, privately view it, then hide it. Seen cards dim so the group can track progress. Once everyone has seen their card, start the discussion, vote, and reveal the impostor(s).

The Locations category includes general locations, San Diego landmarks, SDSU campus nicknames (Stacks, Cabana, Barn, and Prison), and major cities around the world. The People and Freak Time categories each use a custom one-entry-per-line list saved only in the current browser, so you can build them up over time. Custom lists are included in Surprise me when they are not empty.

No build step, account, or server is required.
