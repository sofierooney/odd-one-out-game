# Odd One Out

A pass-the-phone impostor party game for 3–20 players. Everyone gets the same secret word except 1–3 randomly chosen impostors, who see the category but not the word. The player list starts with sof, mont, meegs, marj, ava, saff, viv, summz, and lior.

## Play

Open `index.html` in a browser. Edit the player list if needed, choose a category (or leave it on Surprise me) and 1–3 impostors, then deal the cards. You need at least 3 players and at least one more player than the number of impostors. Pass the phone so each player can privately reveal their role. After everyone has seen their card, give clues, vote as a group, and reveal the impostor(s).

The Locations category includes general locations, San Diego landmarks, SDSU campus nicknames (Stacks, Cabana, Barn, and Prison), and major cities around the world. The People category uses a one-name-per-line list saved only in the current browser, so you can build it up over time. People are also included in Surprise me when the list is not empty.

No build step, account, or server is required.
